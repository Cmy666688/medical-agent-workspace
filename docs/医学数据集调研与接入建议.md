# 医学数据集调研与接入建议

核查日期：2026-11-01（北京时间）。本轮完成来源、下载入口、许可说明与实际文件结构核查；没有把新数据接入线上 Agent，没有训练或替换风险模型，没有向 LLM API 发送这些记录。

### TFDA：已验证的中文药品数据

- 官方来源：[许可证数据](https://data.gov.tw/dataset/9122)、[仿单与外盒](https://data.gov.tw/dataset/9117)、[药品外观](https://data.gov.tw/dataset/9120)。发布机构为食品药物管理署，数据集页面注明免费、每 7 日更新、采用政府资料开放授权条款第 1 版。
- 三份 ZIP 均已从发布方地址成功下载，内部 JSON 列表已解析并核对字段。用许可证字号连接三个数据集，可获得中文/英文品名、主成分、剂型、适应症、许可有效期，以及说明书/外盒/外观图链接。
- 先检查注销状态、有效期、剂型和成分；保留繁体原名、原始许可证号与地区标签，再建立经过核对的简体/英文检索别名。不能将 TFDA 记录冒充大陆 NMPA 批准记录。
- 说明书索引不含完整禁忌及相互作用章节，仍需获取相应原文后抽取、核对。链接指向的包装或图像应检查原件版本和权利范围；本轮没有批量抓取附件。

### openFDA：用药证据的首选起点

- [官方字段说明](https://open.fda.gov/apis/drug/label/searchable-fields/)、[调用方法](https://open.fda.gov/apis/drug/label/how-to-use-the-endpoint/)、[条款](https://open.fda.gov/terms/)。
- 本次查询 ibuprofen、acetaminophen、amoxicillin、metformin hydrochloride、warfarin sodium；原始 JSON 保留服务端 `meta` 和标签记录。
- 可用字段包括 `id`、`set_id`、`effective_time`、`openfda.generic_name`、`contraindications`、`drug_interactions`、`warnings` 等，具体标签并不都有这些字段。下载的对乙酰氨基酚样本有 `warnings`，没有独立的 `drug_interactions` 字段；不能把字段缺失解释为没有相互作用。
- 许可：官方条款原则上采用 CC0，但明确保留第三方版权内容例外；不能据此声称所有药品包装、图片及提交材料均可无限制再发布。
- 接入时用通用名、成分、剂型、规格、厂商和版本限定检索，显示原文及来源；中文名称映射需单独审核。

### DDInter：相互作用结构数据

- [官方下载页](https://ddinter2.scbdd.com/download/)、[统计](https://ddinter2.scbdd.com/statistics/)、[许可](https://ddinter2.scbdd.com/terms/)。官方统计页列出全站 302,516 条 DDI，并另有食物/疾病相互作用；本次没有下载全站这些内容。
- 本地 A 类文件字段为 `DDInterID_A, Drug_A, DDInterID_B, Drug_B, Level`。
- 实测等级分布：Moderate 33,057；Major 4,906；Minor 3,637；Unknown 14,767。Unknown 需要保留为未知，未命中也不能展示为安全。
- CC BY-NC-SA 4.0：保留署名、非商业及相同方式共享要求。课程研究可按条款评估使用；商业部署需另行明确授权。
- 接入应建立药物名称/成分标准化和无序药物对索引，保留来源、下载版本、已覆盖子集。原 CSV 没有的机制或处置结论不能让模型补造。

### MIMIC-IV-ED Demo：实际核查结果

- [官方资源与许可证](https://physionet.org/content/mimic-iv-ed-demo/2.2/)、[完整 ED 字段说明](https://physionet.org/content/mimic-iv-ed/2.2/)。Demo 可公开下载，许可 ODbL 1.0；完整 ED 数据需要认证、培训和 DUA。
- 官方介绍选取 100 位患者作为 Demo 基础集合；本次下载的 ED 分诊表实际出现 64 个不同 `subject_id`、222 次就诊，不应把 100 写成该表实际患者数。
- `triage`：`temperature, heartrate, resprate, o2sat, sbp, dbp, pain, acuity, chiefcomplaint`，另有患者与就诊连接键。`acuity` 为人工分诊等级，1 最紧急、5 最低，不能解释为患病概率。
- 当前分诊标签：1 级 18 条、2 级 97 条、3 级 90 条、4 级 2 条、5 级 0 条、缺失 15 条。有效标签只有 207 条，不能据此证明五级分类有效性。
- `vitalsign` 1,038 行、`diagnosis` 545 行、`medrecon` 2,764 行、`pyxis` 1,082 行。所有 6 个压缩 CSV 的 SHA-256 均与发布方校验文件一致。
- 用途：补齐风险 Agent 所需的真实输入结构、缺失值处理和离线流程测试；正式模型须扩大经授权数据并进行外部验证。

### UCI 与 NHANES：慢病风险研究资料

- [UCI Heart Disease 官方页](https://archive.ics.uci.edu/dataset/45/heart+disease)：CC BY 4.0；Cleveland 常用子集含年龄、性别、胸痛类型、静息血压、胆固醇、心率等变量，最后一列是疾病状态。应按患者划分训练/测试集，不把现患分类结果包装成 Framingham 等风险评分。
- [NHANES 血压文档](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/BPXO_L.htm)、[人口学文档](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DEMO_L.htm)、[数据使用教程](https://wwwn.cdc.gov/nchs/nhanes/tutorials/datasets.aspx)：下载了公共使用版本，非受限地理或遗传资料。血压表包含三次收缩压、舒张压和脉搏；人口学表含年龄、性别、权重和抽样设计变量。它适合分析和字段设计，不能凭单次横断面资料训练未来十年发病概率。

## 3. 不应直接采用的快捷方案

- RxNav 可以辅助药名与 RxCUI 标准化，但其药物相互作用功能已于 2024-01-02 停止。[NLM 官方 FAQ](https://www.lhncbc.nlm.nih.gov/RxNav/information/FAQs.html)。不要按旧教程接已停用的相互作用 API。
- Hugging Face 上的 [CN-Drug-KG-800](https://huggingface.co/datasets/Sofun2009/yzint-drug-data) 确有发布记录，声明 CC BY-NC 4.0；页面当前报告实体/关系 JSONL 字段混用导致加载失败，且说明文本缺乏足够逐条原文追溯。本轮只列候选，不视为已验证的药品事实库。
- 疾病百科中的“推荐药物”关系不足以支持剂量、过敏、妊娠禁忌或药物相互作用审查。
- 真实患者历史用药记录不是推荐处方标签；真实分诊等级也不是在家庭场景下经过校准的风险概率。

## 4. 对当前项目的接入顺序

1. 用药 Agent：先建立 TFDA 中文/英文药名、成分及许可索引，结合 openFDA 标签检索及原文引用，再增加 DDInter 已覆盖药物对的确定性匹配。需要单独处理地区差异、中文通用名、复方成分、剂型和缺失项。
2. 风险 Agent：先根据 ED 数据补齐生命体征、单位、缺失字段与离线分诊测试；保留现有即时危险信号提醒。扩大有效数据并完成验证之前，不新增看似精确的临床概率。
3. 问诊/资料解读 Agent：优先以标签、经许可的指南原文作为 RAG 证据；IMCS-21、cMedQA2 优先用于问诊行为和离线评测，而非事实依据。
4. 家庭、留言、提醒 Agent 的核心数据由成员和计划产生，不需要随机引入外部患者记录。NHANES 可帮助设计血压和脉搏字段及分析实验。
5. 识图功能：用 TFDA 外观字段和包装/说明书索引补充可回查的参照来源；这还不是训练完成的识别模型，不把图片相似度解释为药品身份或安全结论。

重新获取本轮小规模数据：在项目目录运行 `.venv\Scripts\python.exe fetch_medical_datasets.py`。这只写入本地 `data/external/`；不修改在线知识库，不执行模型推理或训练。
